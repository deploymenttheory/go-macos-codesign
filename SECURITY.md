# Security reporting

This project is an incomplete code-signing implementation. Its supported trust
model and missing certificate/timestamp policies are documented in
[certificate signing](docs/certificates.md), [timestamps](docs/timestamps.md) and
the [compatibility matrix](docs/compatibility.md).

As checked on 2026-09-19, this repository has no published releases and GitHub
private vulnerability reporting is not enabled. To arrange a private report,
open a minimal [repository issue](https://github.com/deploymenttheory/go-macos-codesign/issues)
asking the maintainers for a private contact channel. Do not include exploit
details, private signing keys, passwords or sensitive binaries in that public
request. Use the private channel once a maintainer provides it.

The repository's [Security tab](https://github.com/deploymenttheory/go-macos-codesign/security)
shows any subsequently enabled reporting options. GitHub's own bug-bounty
program is not the reporting channel for vulnerabilities in this project.
